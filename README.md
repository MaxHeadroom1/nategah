# Engineering Study Hub | مواد هندسة عين شمس

ريبو عام مخصص لمراجعة مواد هندسة عين شمس، وتصميمه متوافق مع الموبايل بخط **Cairo**.

## المواد المتاحة

| المادة | المراجعة | الرابط داخل المشروع |
|---|---|---|
| CES251s — Concrete Technology (1) | Midterm 2024, Model B: 30 MCQ, explanation first, answer feedback, timed exam | [ces251midterm/](./ces251midterm/) |

## شكل الملفات

```
index.html                  # صفحة فهرس المواد
ces251midterm/
    index.html              # امتحان الخرسانة 2024 وشرح كل سؤال
```

## إضافة مادة جديدة

أنشئ مجلدًا مستقلًا لكل مادة (مثل `ces262/`) ثم أضف رابطًا إليها في فهرس `index.html`.

## الاستضافة

موقع static HTML بدون build أو API. يمكن نشره عبر GitHub Pages من الفرع `main` ومجلد `/(root)`.
**تنبيه:** وجود الملفات في GitHub وحده لا يعني أن GitHub Pages مفعّل. يلزم إعداد Pages من Settings → Pages قبل مشاركة الرابط العام.

لا يتضمن امتحان 2021 أو Fresh Concrete في مراجعة CES251s.
